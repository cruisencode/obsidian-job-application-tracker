# Job Application Tracker

An Obsidian plugin to track and manage job applications throughout your job search process.

## Features (Planned)
- Track job applications, statuses (Applied, Screening, Interviewing, Offer, Rejected, etc.)
- Kanban / Table / List views
- Application details (Company, Role, Salary, Date Applied, Contacts, Notes, URLs)
- Metrics and search statistics

## Development

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Installation & Setup
```bash
npm install
npm run dev   # Build and watch for changes
npm run build # Production build
```
